# Filesystem C bridge and native composition — 2026-10-18

UL-082 remains active. The [maintained bridge](../../../experiments/filesystem-service/bridge.rs)
owns one noncloneable C context under an exclusive SPA borrow, preserves live
nonaliasing synchronous buffers and truthful write progress, clears erroneous read
outputs and consumes close once. Shared UTC is read from the existing established
runtime anchor; no initialization/reset/native authority is invented. Close leaving
a nonnull pointer is a deliberate panic-abort boundary, not successful cleanup.
