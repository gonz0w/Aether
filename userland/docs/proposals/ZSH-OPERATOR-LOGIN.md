## Session contract

The closed `native_zsh_operator_login` Rust profile requires the complete166
composition. The Owner validates the held HOME directory before publishing
startup and PWD=/home. Real Zsh automatically sources the existing persisted
.zprofile. The same guest supports manual serial attachment and the fixed
foreground qualification; manual input has no scripted-byte or PID claim.

Clean exit is allowed with a genuinely unused helper, or after any completely
settled successful helper execution that fits the remaining resources. At most
one child is live. Every next admission requires real status23/exec/READY/wait,
FILE/endpoint settlement, confirmed reclaim and restored parent READ lease.
Native generations remain monotonic1..15; this ceiling does not promise15 runs.
The Owner fully revalidates later executable bytes through held HOME, recording
each epoch's attempt before effects. Same-epoch retries cannot rearm, including
after known native refusal. Preserve poison, quotas, history and closed-handle
lifetimes; save the672-byte exec request outside workspace before reads.

Before admitting effects, fund the complete operation and close/shutdown credits.
A resource refusal sends a real correlated negative fork/FILE receipt, preserving
the settled parent. The caller's existing freeze must be authenticated and
cancelled/resumed through the existing controls; no child is admitted by refusal.
Parent CWD/profile operations preserve their own completion/close credits, even
for short reads. Unknown or partial effects remain contained, never reset/replayed
or reported as a clean resource refusal.
