# Security reporting

Report suspected vulnerabilities privately to **security@aethersys.org**.
The maintainer supplied this address on 2026-09-06. Avoid posting exploit details,
credentials or private package contents in a public issue while reporting privately.

Include the affected revision/artifact digest, environment, expected and observed
behavior, impact and a minimal safe reproduction. Use disposable private roots;
do not test against a real install prefix or another person's system. Omit secrets
and usable grants from logs.

pkg-mgr is experimental. No supported production release, response-time guarantee,
disclosure deadline or security-support period is declared. Triage owner assignment,
mailbox operational verification and support commitments remain publication gates.
No test email was sent. Publishing an address does not prove receipt or review.
See [release scope](docs/AETHER-RELEASE.md) for limitations.
