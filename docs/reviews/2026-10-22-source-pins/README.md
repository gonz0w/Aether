# Historical tooling inputs

These seven files are exact read-only provenance inputs for existing sealed build
artifacts. Do not execute them as current tooling or edit their bytes. The catalog
and every selected file are hash-checked by `scripts/source_paths.py`. Current
commands live under root `scripts/`; see [the repository guide](../../REPOSITORY.md).
No kernel, service, ABI or executable binary is substituted by this mechanism.
