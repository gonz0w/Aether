# ABI24 companion intake

Before-work scope: consume the newly sealed userland wait-aware runtime and actual
sys-init serial-session entry. Verify selected manifest hashes and every packet
member before consuming code/data, then independently boot the delivered sys-init
normal and semantic rejection artifacts using their matched kernel/client closure.
Preserve the retained failed delayed run; successful replay must not close its
unexplained guest invariant failure. No sibling edits, runtime refactor, new ABI,
released-pin change or owner acceptance on behalf of a companion.

Aether owns kernel enforcement, userland the runtime, sys-init the actual entry
and final-action policy. Inputs remain private unpublished candidates. The owned
entry shares the borrowed dispatcher's authority/TCB/failure domain and fixed
24KiB code/4088-byte stack limit. Artifact checks distinguish genuine entry from
fixture renaming, same kernel/client bytes from relabeled profiles, and confirmed
cleanup/halt from boot/prompt alone. Existing namespace and numeric IDs grant no
new authority. Borrowed code is inspected but not executed on the host; QEMU is
the existing pinned offline test runner with owned writable firmware variables.

Tests: all sealed input hashes/member readback; immediate and35-second delayed
boot/workload/identity/ten-reclaim/halt using the actual sys-init image; wrong ABI
and pre-admission busy halt reject for exact reasons; retained independent oracle
and its corrupted trace controls; local pin/workflow/host checks. Record all
attempts, source/tool identities and remaining failed-run limitations in STATE,
ROADMAP, COMPANION-PROJECTS and NATIVE-CONNECTIONS. Archive and verify only new
temporary roots before cleanup. Do not mark assembled R1, broad TTY/signals,
persistence/packages or a complete cleanup matrix accepted.

Simplicity: replaying delivered components is smaller and more direct than
rebuilding a duplicate entry or runtime here. No new dispatch seam or server is
needed now that sys-init supplies its entry. This review removes obsolete
dependency-blocked status without removing historical evidence or compatibility.
