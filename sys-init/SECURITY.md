# Security reporting

Report suspected security issues privately to **security@aethersys.org**.
The maintainer supplied this reporting contact on 2026-09-06. No delivery test
or response-time guarantee is claimed by this document.

Include the affected source revision, host or native profile, expected and
observed behavior, and the smallest reproducible example you can share safely.
Identify whether the result came from a model, host fixture or Aether target.
Do not send credentials, usable capability values or unrelated private data.
Please coordinate public disclosure through the reporting address while the
maintainer assesses impact and a correction.

sys-init is experimental and has no published supported release or established
maintenance window. A passing test or source review is not a security
certification. Reports are triaged by the sys-init maintainer; release/support
policies and independent technical review remain separate acceptance work.
For ordinary non-security bugs, use the project's normal contributor workflow.
